# UC15
Projeto de conclusão do curso técnico de ADS do SENAC.

Status: Desenvolvido

O stack do projeto é como segue abaixo:

Development ToolKit:

Java 25.0.2

IDE:

Apache NetBeans IDE 29

Banco de dados:

MySQL Workbench 8.0.46

Extensões e dependências:

Spring (Spring Web, Spring Data JPA, MySQL Driver, Lombok, Thymeleaf, Validation)

Time: Solo

Objetivo: Servir como sistema de cadastro de livros simples.

Funcionalidade:

Requisitos Funcionais:

Autenticação de usuário

Encerramento de sessão

Cadastro de Livros

Catálogo de Livros

Requisitos Não Funcionais:

Persistência de Dados via Mysql

Arquitetura MVC
